### Автор проекта - единственный -  Дайдиев Рашид

## описание проекта

я разработал `aviation_parts` — пакет на Python с предметной моделью и каталогом авиационных деталей

в программе можно создавать авиационные детали, добавлять их в каталог, искать, удалять, сохранять в JSON и загружать из JSON

## возможности программы

- создание авиационных деталей через `dataclass`
- проверка инвариантов при создании
- добавление, получение и удаление деталей
- поиск по категории и имени
- поиск по ID через словарь
- запрет дубликатов ID
- поиск по имени без учета регистра
- детерминированный порядок итерации
- сохранение каталога в JSON
- загрузка каталога из JSON
- поле `format_version` в корне документа
- защита от частичного изменения каталога при ошибке загрузки
- обработка ошибок через собственные исключения

## сущность

для авиационной детали используется `@dataclass(frozen=True)`

каждая деталь содержит:

| поле | описание |
|---|---|
| `id` | уникальный строковый идентификатор |
| `name` | название |
| `category` | категория |
| `year` | год |
| `weight` | масса |
| `material` | материал |

инварианты проверяются при создании через `__post_init__`

неверный объект не должен появляться в каталоге

## каталог

все детали хранятся в словаре, где ключ — ID, а значение — объект `AviationPart`

| метод | назначение |
|---|---|
| `add(item)` | добавление детали |
| `get(item_id)` | получение детали |
| `remove(item_id)` | удаление детали |
| `find_by_category(category)` | поиск по категории |
| `find_by_name(query)` | поиск по имени |
| `__len__()` | количество деталей |
| `__iter__()` | перебор деталей |
| `__contains__(item_id)` | проверка наличия ID |
| `save(filename)` | сохранение каталога в JSON |
| `load(filename)` | загрузка каталога из JSON |
| `read_only()` | просмотр деталей без изменения |

порядок итерации — **по порядку добавления деталей в словарь**

## хранение

каталог сохраняется в JSON

пример файла:

```json
{
    "format_version": 1,
    "items": [
        {
            "id": "123",
            "name": "крыло",
            "category": "корпус",
            "year": 2020,
            "weight": 150.5,
            "material": "алюминий"
        }
    ]
}
```

`format_version` — версия формата JSON, сейчас поддерживается версия `1`

поврежденный документ не должен частично изменять существующий каталог

для этого при загрузке сначала создается новый словарь, и только после проверки всех деталей он заменяет старый

## исключения

создан базовый `CatalogError` и отдельные ошибки:

| ошибка | назначение |
|---|---|
| `InvalidPartError` | неверная сущность |
| `DuplicateIdError` | дубликат ID |
| `PartNotFoundError` | объект не найден |
| `UnsupportedVersionError` | неподдерживаемая версия формата |
| `CorruptedFileError` | поврежденный файл |

## запуск программы

запускаем из корневой папки проекта

```bash

```

при запуске создается каталог, добавляется одна авиационная деталь и выводится ее название

результат:

```text

```
